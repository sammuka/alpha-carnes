Fundações

Mundo visual novo para operação intensiva: neutros frios quase-monocromáticos, sidebar grafite plana, um único accent índigo, borda 1px como divisor primário e cor reservada quase exclusivamente para status semântico. Base 13px, tabelas a 12px, linhas de 32px.
